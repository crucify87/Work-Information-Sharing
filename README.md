# work-information-sharing

생산, 물류, 재고, 회계 부서가 같은 화면에서 업무 흐름을 공유하는 웹앱입니다.

배포 주소: https://business-work-hub.workspace-910868.chatgpt.site

## 주요 기능

- 부서별 업무 필터와 담당자 검색
- 새 업무 등록 및 브라우저 로컬 저장
- 생산, 출고, 재고, 미수 KPI 카드
- 부서 인계 현황과 재고 알림
- 오늘 마감 체크 목록

## 실행 방법

```bash
npm install
npm run dev
```

## 검증

```bash
npm run build
npm run lint
```
